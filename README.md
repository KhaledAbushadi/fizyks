# فيزيكس بالمصري (فُكّها)

مدرّس فيزياء تفاعلي لطالب واحد في الصف الثالث الثانوي (دفعة 2027). تطبيق ويب يُثبَّت على الموبايل ويعمل دون إنترنت بعد أول فتح. **صفر مدفوعات، صفر حسابات، صفر بيانات تغادر الجهاز.**

النسخة الأولى: **الفصل الأول كاملاً** (التيار وقانون أوم وقانونا كيرشوف) + **صالة الرياضيات**. المحرك عام: إضافة فصل = إضافة ملفات محتوى فقط.

## ما الذي يراه الطالب

| الشاشة | الفكرة |
|:--|:--|
| خطة النهارده | 3 مهام فقط يختارها التطبيق: مهارة رياضية ضعيفة ← أخطاء مستحقة ← بطاقات ← الدرس التالي |
| رحلة الدرس | 8 محطات: الخطّاف ← تنبّأ (إلزامي) ← شوف (معمل تفاعلي) ← الحكاية/الصورة/الرمز ← الرموز + "زي ما في الكتاب" ← مثال محلول ← ناقص خطوة/خطوتين ← تذكرة الخروج |
| ورشة المسألة | ارسم ← صنّف ← اجرد ← احسب ← افحص. الدعم يُسحب تلقائياً مع الإتقان (0–1 كاملة، 2–3 مختصرة، 4–5 شكل الامتحان) |
| سلّم التلميحات | 3 تلميحات إلزامية بالترتيب، ثم الحل بعد المحاولة الرابعة، ثم **مسألة توأم لا تُتخطى** |
| المفاهيم الخاطئة | كل بديل خاطئ مربوط بمفهوم له شرح وتشبيه (33 مفهوماً) |
| المعامل | 8 دوائر حية: الشحنات تتحرك بسرعة تتناسب مع التيار، أميتر وفولتميتر حقيقيان، ورسم I–V |
| صالة الرياضيات | الأسس، البادئات، نقل الحدود (بلاطات)، الآلة الحاسبة |
| بنك الأخطاء | 4 أنواع (فهم/قراءة/حساب/وحدات)، وكل خطأ يرجع بأرقام جديدة بعد 1 ثم 3 ثم 7 أيام |
| خريطة الدرجات | 60 خانة ملوّنة بأوزان فصول امتحان 2026 |
| اسأل مساعد مجاني | يظهر بعد التلميح 2، **ينسخ** تعليمة جاهزة (فيها الحل المحسوب للمساعد فقط)، والطالب يلصقها بنفسه. التطبيق لا يتصل بأي خدمة |

## التشغيل

```bash
npm ci                 # Node 22
npm run dev            # خادم التطوير (المسودات ظاهرة تلقائياً)
npm run validate-content
npm test               # Vitest: المحرك، المحتوى، التخزين
npm run build          # يشغّل validate-content أولاً ثم البناء في dist/
npx playwright test    # 16 اختبار طرفي على مقاس 390×844 (يحتاج: npx playwright install chromium)
npm run build:preview  # نسخة معاينة: المسودات ظاهرة، بلا Service Worker (dist-preview/)
```

## المحتوى والمراجعة

- كل ملفات `content/` حالتها `"status": "draft"`. **في نسخة الإنتاج لا يظهر للطالب إلا `reviewed`.**
- للتجربة الأولى مع الأسرة: المس الشعار في الشاشة الرئيسية **5 مرات** لإظهار المسودات (ونفس الحركة للإخفاء).
- المراجِع يفتح "المزيد ← معاينة المحتوى" (`#/dev/content-preview`): كل قالب بثلاث نسخ مولَّدة مع الحل والبدائل ومفاهيمها. يصحح في JSON مباشرة ثم يغيّر الحالة إلى `reviewed`.
- قواعد الكتابة في `content/STYLE.md`. أي خطأ في ملف محتوى يوقف البناء برسالة عربية واضحة.
- قائمة الدروس ونصوص صندوق "زي ما في الكتاب" مأخوذة من كتاب الوزارة المرفق (الفصل الأول). الثوابت في `content/constants.json` بحالة `verified: false`، ومعها `bookValue` كما وردت في ملحق 2 (ثابت بلانك: اعتمدنا قيمة الكتاب 6.63×10⁻³⁴ بقرار خالد).

## النشر (مجاناً، بلا بطاقة دفع)

**الخيار 1: Cloudflare Pages**
```bash
npm run build
npx wrangler login                                   # مرة واحدة بحساب خالد
npx wrangler pages deploy dist --project-name fukkaha
```
لو طلبت Cloudflare بطاقة دفع في أي خطوة: توقّف واستخدم الخيار 2.

**الخيار 2 (المفعّل): GitHub Pages** عبر `.github/workflows/deploy.yml`: يتحقق من المحتوى ويشغّل الاختبارات ويبني وينشر عند كل دفع على `main`. الرابط: https://khaledabushadi.github.io/fukkaha/

البناء يستخدم `base: './'` وموجّه hash، فنفس `dist/` يعمل على أي مسار.

## محاكاة PhET

لم أستطع تنزيل ملف المحاكاة من بيئة البناء (رد 403)، فطبّقت البديل المذكور في الخطة: زر "افتح معمل PhET (محتاج نت)" **لا يحمّل شيئاً إلا بلمسة من الطالب**، ويعرض رسالة لطيفة لو مفيش نت، ومعه سطر النسب الإلزامي حرفياً. المعامل الثمانية المدمجة تعمل دون اتصال وتغطي نفس الأفكار.

لإضافة نسخة محلية لاحقاً (من جهاز فيه نت):
```bash
curl -fL -o public/sims/circuit-construction-kit-dc_ar.html \
  https://phet.colorado.edu/sims/html/circuit-construction-kit-dc/latest/circuit-construction-kit-dc_ar.html
```
التطبيق يكتشفها تلقائياً ويفضّلها على الرابط المباشر.
